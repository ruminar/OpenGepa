# OpenGepa v0.4.1 FileItem表示名

## 目的

通常アプリランチャーへ登録した文書、画像、表計算ファイルなどを、実行ファイルと見分けられるようにする。

## 仕様

- 新規の `FileItem` を外部ファイルから作成するとき、`.exe`、`.lnk`、`.bat`、`.cmd`、`.ps1` 以外は初期表示名を `>` + ファイル名とする。拡張子の大文字・小文字は区別しない。
- 実行ファイル、ショートカット、スクリプトの初期表示名は従来どおりファイル名だけとする。
- 対象は通常アプリランチャーの新規 `FileItem` だけとし、UrlItem、DirectoryItem、Group、SeparatorItem、Windows Menu、ストアアプリ、Windows主要操作を変更しない。
- Start MenuショートカットおよびOpenGepa管理ショートカットを新規作成する際の名前候補にも `>` を付けない。
- `>` は表示名の一部であり、新しいNode種別を追加しない。保存形式、Profile formatVersion、起動処理、MCPのNode種別を変更しない。
- 既存のFileItemは自動改名しない。利用者が変更した名前や、起動対象の変更後の名前を自動変更しない。
- OpenGepa内部の既存項目を複製・移動する経路、およびWindows Menu、ストアアプリ、起動履歴、使用頻度から通常ランチャーへコピーする経路は、元項目の表示名を維持する。

## 起動記録

起動履歴と使用頻度の生成・表示方式は変更しない。新規FileItemが保持する表示名に `>` が含まれるため、そのFileItemが参照可能な場合は既存の表示規則により結果として `>` 付きで表示される。既存の記録や登録済みFileItemを一括変換しない。

## 適用経路

- 編集画面の［ファイルを追加］
- Windows ExplorerなどからのファイルDrag & Drop
- メイン画面へ外部ファイルをDropして新規FileItemを作る経路
- その他、外部ファイルパスから通常ランチャーへ新規FileItemを作る経路

## テスト

- `.exe`、`.lnk`、`.bat`、`.cmd`、`.ps1` は `>` を付けない。
- `.xls`、`.doc`、`.pdf`、`.png` は `>` を付ける。大文字拡張子も同じ規則とする。
- `>` 付きFileItemの起動記録と使用頻度が `>` 付き表示名を維持する。
- URL、DirectoryItem、既存項目、手動改名、ショートカット作成の名前候補を変更しない。
