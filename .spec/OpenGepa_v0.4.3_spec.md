# OpenGepa v0.4.3 ディスプレイ主要操作

## 目的

ノートPCで利用頻度の高い画面表示・外部ディスプレイ関連の操作を、Windows主要操作タブから分かりやすく実行できるようにする。

## 仕様

- 既存の「GPU 管理」グループは「ディスプレイ」へ名称変更する。項目IDは変更しないため、既存の表示／非表示設定を引き継ぐ。
- 「ディスプレイの設定」を「システムとデバイス」から「ディスプレイ」へ移動する。項目IDは`display-settings`のままとする。
- 「ディスプレイ」グループは次の順で表示する。
  1. ディスプレイの設定
  2. 表示モード切替
  3. デスクトップを表示
  4. 利用可能なGPU管理アプリ
- 「表示モード切替」は`DisplaySwitch.exe`を引数なしで起動し、Windows標準の表示モード選択UIを開く。MCPからは実行できない。
- 「デスクトップを表示」はWindows Shellの`ToggleDesktop`を実行する。すべてのウィンドウを隠してデスクトップを表示し、再実行時は元のウィンドウ表示へ戻す。
- 「デスクトップを表示」は起動履歴および使用頻度に記録しない。MCPからは実行できない。

## 非変更範囲

- 「デスクトップ」は従来どおりエクスプローラーでデスクトップフォルダーを開く項目として残す。
- 「システムとデバイス」のその他の項目、GPUアプリの検出条件、項目ごとの表示／非表示設定は変更しない。

## テスト

- ディスプレイグループの先頭3項目が、ディスプレイの設定、表示モード切替、デスクトップを表示の順になる。
- デスクトップを表示は起動記録の対象外である。
- MCP許可プリセット一覧に表示モード切替およびデスクトップを表示を含めない。
