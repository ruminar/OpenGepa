# OpenGepa 開発ルール

## 配布物

- Windows x64向けの通常配布ZIPは、.NETランタイムを同梱しないフレームワーク依存型とする。
- 発行時は`--self-contained false`を指定し、単一EXE化せず発行ディレクトリ全体をZIP化する。
- 利用者には.NET 10 Windows Desktop Runtime x64が事前に必要であることをREADMEへ明記する。
- ZIP名は原則として`OpenGepa-{version}-win-x64.zip`とする。検証用・修正版を並行して作る場合は、接尾辞を付けて通常配布物と明確に区別する。
- .NET 10 Windows Desktop Runtime x64を導入できない環境向けには、`build-selfcontained.ps1`で`OpenGepa-{version}-win-x64-self-contained.zip`を作成できる。これは`win-x64`・Release・自己完結型・非単一ファイルの配布物とし、通常配布物とは出力先を共有しない。
- 自己完結版には、発行に使用した`dotnet`のルートにある`.NET`の`LICENSE.txt`と`ThirdPartyNotices.txt`を明示的に同梱し、ZIP生成後の必須ファイル検査にも含める。
- 自己完結版は必要時に作れる開発環境としてのみ維持する。通常のリリース作業では生成せず、GitHub Releaseの添付ファイルにも含めない。自己完結版の生成・配布は、利用者から明示的に依頼された場合だけ行う。

## 仕様と実装

- 振る舞いの正本は`.spec`配下の仕様書とし、仕様変更は実装より先に記録する。
- Windows環境から生成するタブのデータとアイコンは、OpenGepaのJSONやProfileへ永続化しない。
- 既存利用者の設定ファイル・アイコン・Profileを、明示した移行処理以外で上書きしない。
