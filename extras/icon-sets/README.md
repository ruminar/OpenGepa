# OpenGepa アイコンセット

このディレクトリには、OpenGepaで使用できるアイコンセットと、ChatGPTを使って新しいアイコンセットを作るための資料があります。

## 収録アイコンセット

| ファイル | 内容 |
|---|---|
| `iconSet_default.zip` | OpenGepaの標準アイコンセット |
| `iconSet_cherry.zip` | 桜をテーマにしたアイコンセット |
| `iconSet_halloween.zip` | ハロウィンをテーマにしたアイコンセット |

### OpenGepaで使う

1. 使用したいZIPを選びます。
2. OpenGepaを終了します。
3. ZIPを、`OpenGepa.exe`があるディレクトリへ展開します。
4. `OpenGepa.exe`と`iconSet`ディレクトリが同じ階層にあることを確認します。
5. OpenGepaを起動します。

```text
OpenGepa/
├─ OpenGepa.exe
└─ iconSet/
   ├─ appIcon1.png
   ├─ appIcon2.png
   ├─ urlIcon1.png
   ├─ urlIcon2.png
   ├─ winMenu.png
   ├─ winStore.png
   ├─ winCust.png
   ├─ history.png
   └─ frequency.png
```

既存の`iconSet`がある場合、同名ファイルを置き換えると新しいデザインが適用されます。必要なら、置き換える前に現在の`iconSet`をバックアップしてください。

## ChatGPTで新しいアイコンセットを作る

次の2ファイルを、同じChatGPTの会話へ添付します。

- [`アイコン生成依頼文.md`](アイコン生成依頼文.md)
- [`OpenGepa緑アイコンSet.png`](OpenGepa緑アイコンSet.png)

添付後、例えば次のように依頼します。

> 添付した「アイコン生成依頼文.md」に従い、「OpenGepa緑アイコンSet.png」を参考画像として、OpenGepaのアイコン画像を生成してください。

生成依頼文は、参考画像を`Image A`として扱い、9種類のアイコンを3列×3行の一枚の画像として生成する内容です。参考画像の具体的な構図を複製するためではなく、線、塗り、配色、質感の方向性を揃えるために使用します。

### 別の配色やテーマへ展開する

最初の画像が生成された後は、同じ会話で配色やモチーフを追加指定できます。

例えば、冬向けのセットにする場合は次のように依頼します。

> 色は白ベースで、雪だるまなど雪をテーマにアイコンを生成してください。9種類の役割、3列×3行の配置、統一した描画スタイルは維持してください。

ほかにも「桜色を中心にする」「ハロウィンのモチーフを加える」「青と銀を中心にする」のように指定できます。機能を表す基本モチーフと9種類の配置を維持するよう伝えると、OpenGepa用のファイルへ分割しやすくなります。

画像生成の結果は毎回少し異なります。文字や番号が混入していないこと、9個が接触していないこと、各アイコンの役割を判別できることを確認してください。必要なら同じ会話で修正を依頼します。

## 生成画像をOpenGepa用ファイルにする

生成される画像は3列×3行の一枚絵です。OpenGepaで使用するには、各セルを正方形に切り出し、純白の背景を透明にして、256×256px以下のPNGとして保存します。

ファイル名は左上から右へ、上の行から順に次のように割り当てます。

| 位置 | 機能 | ファイル名 |
|---|---|---|
| 1行1列 | アプリランチャーA | `appIcon1.png` |
| 1行2列 | アプリランチャーB | `appIcon2.png` |
| 1行3列 | URLランチャーA | `urlIcon1.png` |
| 2行1列 | URLランチャーB | `urlIcon2.png` |
| 2行2列 | Windows Menu | `winMenu.png` |
| 2行3列 | ストアアプリ | `winStore.png` |
| 3行1列 | Windows主要操作 | `winCust.png` |
| 3行2列 | 起動履歴 | `history.png` |
| 3行3列 | 使用頻度 | `frequency.png` |

完成した9ファイルを`iconSet`ディレクトリへ入れます。配布用ZIPを作る場合は、ZIPを展開した時に`iconSet`ディレクトリごと作成される構造にしてください。

```text
作成するZIP
└─ iconSet/
   └─ 9個のPNGファイル
```

## 生成依頼文を変更する場合

配色だけを変える場合は、生成依頼文を編集せず、画像生成後の同じ会話で追加依頼する方法が簡単です。恒常的に別のデザイン方針を使う場合は、`アイコン生成依頼文.md`の［今回の配色方針］や全体デザインを編集してください。

生成依頼文にある9種類の順番は、上記のファイル名との対応に使います。順番を変えた場合は、切り出したPNGのファイル名も対応させてください。
